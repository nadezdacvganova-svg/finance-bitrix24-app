# Финучёт

Веб-приложение для ручного финансового учёта доходов и расходов по проектам.

## Возможности

- доходы, расходы, прибыль и рентабельность по каждому проекту;
- показатели доходов, расходов, прибыли и рентабельности всего портфеля;
- статьи доходов и расходов с возможностью добавления новых;
- участники проекта;
- общий журнал финансовых операций;
- подготовленный интерфейс подключения к Битрикс24 без активной интеграции.

## Запуск

```bash
pnpm install
pnpm run typecheck
```

В Replit приложение запускается через настроенные workflows API-сервера и frontend.

## Структура

- `artifacts/finance-bitrix24` — frontend на React/Vite;
- `artifacts/api-server` — API-сервер;
- `lib/db` — схема PostgreSQL и Drizzle;
- `lib/api-spec` — OpenAPI-контракт.
